# remotecontrol-python_OOP
A remote control simulator for python. Made using OOP.

# 📺 Simulador de Controle Remoto em Python

Um projeto interativo de terminal construído em Python, focado em **Programação Orientada a Objetos (POO)** e design visual no terminal.

## O que o projeto faz?
* Simula os estados de uma TV (Ligada/Desligada).
* Navegação circular de canais (1 ao 5).
* Controle de volume com limites pré-estabelecidos e barra visual.
* Tratamento de erros e comandos inválidos para evitar que o programa quebre.
